## Overview

This repository organizes LeetCode practice solutions into topic-based folders and monthly Problem of the Day collections. It is intended as a reference for reviewing problem-solving approaches and common data-structure and algorithm patterns. The repository contains judge-style solution snippets rather than a standalone application.

## Features

- Topic-based collections for trees, stacks, heaps, greedy algorithms, and more.
- Monthly Problem of the Day folders.
- Primarily C++ solutions, with a small number of Python solutions.
- Solutions use LeetCode-style `Solution` classes and judge-provided types where needed.

## Getting Started

### Prerequisites

- Git
- A C++ compiler for C++ solutions
- Python 3 for Python solutions

### Installation

```bash
git clone https://github.com/Pruthvi5559/LeetCode.git
cd LeetCode
```

### Environment Variables

No environment variables are required. This repository does not include an `.env.example` file.

### Running Locally

These files are generally LeetCode submission snippets, not standalone programs. Many rely on declarations, headers, or data structures provided by the judge, so there is no repository-wide development or production run command. Open a solution and submit it in the corresponding LeetCode problem environment.

## Usage

1. Browse a topic folder or a monthly `POTD` folder.
2. Open the solution file for the problem.
3. Review or copy the solution into the matching LeetCode problem editor.
4. Run the problem using LeetCode's test cases.

For example, [`Stack/01NGE1_496.cpp`](Stack/01NGE1_496.cpp) contains a C++ solution for Next Greater Element I.
